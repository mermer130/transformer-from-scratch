从0到1实现Transformer（教学版）

从一句文本怎样变成张量开始，依次写出位置编码、注意力、编码器、解码器、训练和束搜索。每一步只交付一个函数，最后得到一套能跑通前向与训练的 Transformer。

How to run

python scaffold.py
